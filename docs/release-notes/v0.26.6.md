## Changes
- **Connect to a moved OpenCode V2 server** — when the configured address stops answering because OpenCode has registered its background server on another port (for example after a self-update), `/opencode_start` and auto-restart now connect the bot to that server instead of failing.
- **One-line compact summary** — in compact mode a finished progress message turns into a single line of what that stretch of work did (`✅ commands: 3, reads: 4, changed files: 2`), leaving out zero counts, and is removed when there is nothing to count.

## Fixes
- **Waiting input on session pick** — picking a session in `/sessions` that is still replying now also shows the newest message still waiting for its reply. ([@atn18](https://github.com/atn18))
- **Commands after a session pick** — picking a session that is still streaming no longer leaves the bot ignoring your commands until that stream calms down. ([@atn18](https://github.com/atn18))
- **Microsoft Edge voice replies** — text-to-speech through Microsoft Edge works again after the service started rejecting the bot's requests. ([@Realmagnum](https://github.com/Realmagnum))
- **Images sent as files** — images that Telegram delivers as generic files without an image type are now recognized and sent to the model as images. ([@vinceferro](https://github.com/vinceferro))
